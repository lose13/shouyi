# 守忆交付入口

当前作品的参赛交付目录为 **守忆/**。该目录根层放置守则、最终角色记忆和 DOCX 策略报告，应用统一位于 **守忆/app/**。

1. 打开 `守忆/app` 文件夹。
2. 双击 `start.bat`。
3. 浏览器打开本机工作台，选择官方28轮回放或自由试验。

需要Python 3.10或更新版本；没有额外包依赖。项目内的README包含功能、能力边界及检查方法。

新项目只以任务书和官方对话输入为依据，代码、守则与界面均独立实现。

当前为v2.6，由LLM阅读守则并作出语义记忆决策；开头是核心原则，实际本轮上下文后追加来自守则的系统级易错检查。实际操作仍为唯一执行清单。2026-10-16通过实际应用完成官方28轮，28次DeepSeek调用，无格式修正或整轮失败；根目录记忆由真实状态导出，没有本地规则替代模式。部分回复有所改善，但旧幼儿园事实误留为待确认等问题仍在，不能声称整体记忆质量已提高。每轮元数据在 `守忆/app/data/official-llm-run.json`，最新说明见应用README、验证说明和质量改动说明。DOCX仍描述历史v2.2.1运行，尚未同步本次结果。

`log.json` 按用户要求暂不处理，交付目录中没有放入占位或模拟日志。最终提交时需将真实导出文件放入 `守忆/` 根目录。

按 `参赛ID_选手名称_3.zip` 命名压缩包；ZIP 打开后应直接看到 `memory-rules.md` 等文件和 `app/`，不要再套一层“守忆”文件夹。参赛ID和选手名称尚未填写。

`开发备份/守忆整理前运行资料/` 保存整理前的个人试验状态、临时检查数据、缓存及旧开发压缩包，不属于交付内容。

`开发备份/本地规则版本_停用/` 保存已停用的本地规则代码、测试、旧记忆与旧报告，不属于当前参赛版本。
