# 守忆 (Memory Guardian) · LLM 角色长时语义记忆工作台

> **AI 创新大赛 · 专业赛道参赛作品**  
> 基于大语言模型（LLM）的自主长时语义记忆管理、动态更新与决策审计工作台。

---

## 📖 项目简介

在智能体（Agent）和角色扮演大模型的长期多轮对话中，传统的记忆方案常面临**记忆易遗忘**、**关键信息与琐碎细节混杂**、**虚假事实污染**以及**硬编码规则难以适应复杂语义**的痛点。

**「守忆（Memory Guardian）」** 是一套面向大模型的长时角色记忆治理系统与交互工作台：
- **纯语义守则驱动**：没有本地中文提取硬编码规则，不设预置答案。由大语言模型直接阅读《记忆守则》（`memory-rules.md`），理解对话上下文，自主决策每轮记忆的建立、更新、合并、存疑与遗忘。
- **六类记忆边界清晰划分**：细分 `FACT`（基本背景属性）、`EVENT`（具体事项与分歧）、`GOAL`（主人自身的长远与阶段目标）等独立语义维度，状态与时效解耦。
- **双向证据链与可解释审计**：每条记忆沉淀均必须附带原对话的**逐字证据（Evidence）**、**决策理由（Reason）**和对应的**守则条款索引（Rules Clause）**，彻底告别“黑盒操作”。
- **零依赖单机轻量部署**：服务端使用 Python 3.10+ 原生库编写，无需额外安装庞大的第三方依赖包，双击即可拉起本地可视化 Web 调试工作台。

## 🌟 核心功能与亮点

1. **官方 28 轮全流程真实实跑闭环**：
   - 从空白记忆出发，真实调用大模型完成官方全量 28 轮交互。
   - 28 轮全部一次性成功，28 次请求唯一标识记录在案，无格式崩溃修正、无整轮失败重跑，真实生成 `memory-LIMING.md`。
2. **可视化三栏工作台**：
   - **左栏**：对话历史与分支列表（支持官方回放与自由输入）。
   - **中栏**：真实模型思考过程、逐轮操作（原值与变更值）、逐字证据链与条款溯源。
   - **右栏**：当前角色记忆树全景快照、存疑标记与置信度状态。
3. **安全与隐私脱敏**：
   - 敏感信息（密钥、长证件号）在提交模型前自动脱敏保护；
   - API 密钥仅驻留进程内存，不落盘、不写入浏览器本地存储或交付文件。

## 🚀 快速启动指南

### 环境要求
- **Python 3.10** 或更高版本
- **无第三方 Python 依赖**（使用标准库开发，无需 `pip install`）

### 启动步骤
1. 进入应用目录：`守忆/app`
2. 双击运行 **`start.bat`**  
   *(或者在终端中运行：`python app.py`，若端口冲突可指定 `python app.py --port 8138`)*
3. 脚本会自动打开浏览器，访问本地工作台（默认为 `http://127.0.0.1:8137`）。
4. 在侧边栏**模型设置**填入你的兼容 API 地址、模型名称及 Key（例如 DeepSeek API），即可开始体验或回放官方测试！
